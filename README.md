# CSV / JSON / JSONL ビューア

CSV / JSON / JSONL を表やツリーで表示して探索する、ブラウザだけで動く Web アプリです。

https://mahiya.github.io/json-csv-viewer/

## 使い方
- ファイルをウィンドウにドロップするか、「ファイルを選択」で読み込みます
- テキスト欄に貼り付けて「表示」(Ctrl+Enter / Command+Enter) でも読み込めます。テキスト欄の外で貼り付けると、その内容をすぐに表示します
- CSV: ヘッダのクリックでソート、絞り込み欄で部分一致の絞り込みができます。表計算ソフトからコピーしたタブ区切りのデータも表示できます
- JSON: ノードごとに開閉できるツリーで表示します
- JSONL: 先頭 10 件を、行ごとに開閉できるツリーで表示します

読み込んだ内容はブラウザの中だけで処理し、外部には送信しません。

## ローカルで使う
リポジトリを取得して `index.html` をブラウザで開くだけで動きます。ビルドやサーバは不要です。

## テスト
```
node --test test/

```
